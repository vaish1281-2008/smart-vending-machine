# SmartBite – Smart Vending Machine (Java 27)

A realistic food-vending mini project built with Spring Boot, Spring Data JPA, H2 and a responsive HTML/CSS/JavaScript frontend.

## Run
1. Open this folder in VS Code.
2. Ensure `mvn -version` shows Java 27.
3. Run `mvn clean`.
4. Run `mvn spring-boot:run`.
5. Open http://localhost:8080

## Features
- 12 seeded food/drink items with food photography URLs
- Search and category filters
- Product selection and checkout/change calculation
- Live stock decrement after purchase
- Admin inventory: add/delete products
- H2 database and H2 console at /h2-console
